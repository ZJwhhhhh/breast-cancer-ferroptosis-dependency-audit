# Figure source data

- `Figure1_flow_counts.csv` contains the locked denominators used in Figure 1.
- `Figure5_observed_composition.csv` and `Figure5_standardized_residuals.csv` contain the locked 10×3 derived matrices used in Figure 5.
- `Figure5_global_tests.csv` records the reported global tests and sensitivity analysis.
- Figure 6 is generated from `../audit/Final_Claim_Evidence_Table.csv` and `../audit/Final_Dependency_Audit_Summary.json`.

The Figure 5 matrices are derived outputs. The original permutation null-draw sequence and complete document-level bridge matrix are not archived here; the global test is therefore recorded and checked for internal consistency rather than claimed to have been re-run from raw records.
